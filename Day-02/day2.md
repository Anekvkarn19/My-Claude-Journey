# Day 2 — Prompt Engineering

## 🎯 Objective

The goal of Day 2 was to understand how the quality and specificity of a prompt can affect the response generated by an AI tool like Claude.

I used two approaches for the same topic:

1. A simple/lazy prompt
2. A structured/engineered prompt

The outputs were then compared to understand the impact of prompt structure, context, constraints, and expected output format.

---

## 1. Lazy Prompt

### Prompt Used

> Create an image explaining Prompt Engineering.

### Result

The output was a general visual explanation of prompt engineering. It focused on common prompt engineering techniques and provided a relatively simple educational graphic.

## 🔍 Lazy Prompt vs Engineered Prompt

| Aspect | Lazy Prompt | Engineered Prompt |
|---|---|---|
| Instructions | Very brief | Detailed and specific |
| Context | Minimal | Beginner-focused context |
| Output structure | Not specified | Clearly defined sections |
| Visual requirements | Not specified | Size, colors, style and layout specified |
| Examples | Not specified | Weak vs improved prompt comparison |
| Branding | Not specified | ABTalks challenge included |
| Control over output | Low | Much higher |

---

## 🧠 What I Learned

The biggest takeaway from this experiment was that **better prompting is not necessarily about making a prompt longer. It is about giving AI the right context, constraints, and expected outcome.**

The lazy prompt left many decisions to the AI, which resulted in a more generic output.

The engineered prompt gave Claude much more direction about the audience, content, visual style, structure, and expected result. This made the output more controlled and aligned with the intended purpose.

I also noticed that even with a detailed prompt, the visual result may still require iteration. Claude provided an image concept/layout rather than directly generating the final image in this case.

This showed me that prompt engineering improves control and consistency, but **iteration and refinement are still important when working with AI.**

---

## 💡 Key Takeaways

1. **Context matters** — telling AI who the audience is can change the way information is presented.
2. **Specific requirements improve control** — defining style, structure, dimensions, and content reduces ambiguity.
3. **Output format matters** — clearly specifying the expected structure makes the response easier to use.
4. **Good prompts reduce unnecessary back-and-forth** — the more clearly the goal is communicated, the closer the first output can be.
5. **Prompt engineering is iterative** — even a detailed prompt may need refinement to achieve the desired result.
