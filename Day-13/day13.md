# Day 13 — AI-Powered Job Search with Indeed

## Objective

Today's task focused on using Claude with the Indeed Connector to discover job opportunities matching my profile, analyze match scores, identify skill gaps, and understand current market demand.

## Setup

- Claude effort level: Low
- Indeed Connector: Connected
- Target profile: Computer Science student / aspiring AI & Software Developer
- Target areas: Software Engineering, AI/ML, and Web Development
- Geographic focus: India, with preference toward the Ghaziabad/Delhi-NCR region

## Skill Gap Analysis

### Existing Strengths

- Git & GitHub — strong match
- MySQL — strong match
- JavaScript — relevant for web-development roles
- C++ and Java — existing programming foundation
- AI/ML project experience
- Computer vision and OCR experience
- Problem-solving and project-building experience

### Identified Gaps

- Python should be made more visible/stronger for AI/ML-focused applications.
- No specific React/frontend framework was demonstrated.
- No cloud/deployment experience was shown.
- Specific ML frameworks such as scikit-learn, TensorFlow, or PyTorch should be demonstrated through projects if learned.

## Market Demand Insights

Claude identified these patterns:

- AI/ML internships in the Noida–Gurugram–Faridabad corridor were active and fairly plentiful.
- Many Indian internship listings had vague or missing compensation information.
- “AI Engineer” and “ML Intern” titles can have broad scopes, so actual responsibilities should be checked carefully.
- Python appeared repeatedly across AI/ML opportunities.
- Full-stack and web-development roles commonly expected React or another frontend framework.

## Recommendations

1. Add Python explicitly to my skills only where it can be supported by actual evidence and projects.
2. Name specific ML frameworks when they have genuinely been used.
3. Publish NIRIKSHAK AI, PLACIQ, and GyanSetu on GitHub with clear READMEs.
4. Prioritize fresh job postings first.
5. Consider learning a frontend framework such as React if targeting web/full-stack roles.
6. Build cloud/deployment experience to strengthen internship applications.

## Key Learning

The biggest takeaway from Day 13 was that AI-powered job search can do more than find vacancies. It can compare opportunities with my profile, highlight recurring market requirements, and show where my current skills need improvement.

The search also showed that **Python and practical ML experience are especially important for the AI/ML internship roles that match my current project direction.**

## Important Observation

The Indeed job-detail tool encountered errors during the search, so compensation information could not be reliably retrieved. Job details, availability, and compensation should therefore be verified directly on the original listing before applying.
