# Day 8 — Environmental Health Analyzer

## Objective
Build an interactive environmental health dashboard using Claude.

## What I Built
Created a standalone HTML dashboard that analyzes air and water quality across 11 Indian cities.

## Key Features
- Environmental Health Score
- AQI, PM2.5 and PM10 visualizations
- Interactive city and AQI filters
- City comparison
- Air and water health impact analysis
- Personalized recommendations
- Environmental report card
- Executive summary

## Claude's Role
Claude generated the complete interactive HTML application including the UI, data visualization, filtering logic, scoring system, recommendations, and responsive design.

## Key Learning
The biggest takeaway was seeing how Claude can move from a natural-language product requirement to a functional, interactive application rather than just generating isolated code.
