## Key Learning

The main concept explored today was **iterative development with AI**.

Instead of trying to create the final product with one huge prompt, the workflow separates development into stages:

**Initial Prompt → MVP → Enhancement Prompt → Improved Product**

This approach makes it easier to evaluate what changed between versions and understand how additional instructions influence an AI-generated application.
