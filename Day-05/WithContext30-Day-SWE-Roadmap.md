# 30-Day Software Engineer Roadmap
**For:** Beginner student with Java, C++, Python (basics), JS, HTML
**Time:** 5 hrs/week (~45–60 min/day, 5 days/week)
**Style:** Videos + Projects

---

## How This Roadmap Works
- 4 weeks, each with a **milestone**, **daily tasks (Mon–Fri, ~1 hr each)**, and a **weekend-optional buffer day** for catch-up.
- You already know syntax across several languages — this plan is *not* about learning a new language from scratch. It's about becoming a **problem-solver and builder**: Git, data structures & algorithms (DSA) fundamentals, web basics, and a real project for your portfolio.
- Pick **Python** as your primary language for this roadmap (most beginner-friendly for DSA + web + widely used in SWE interviews). Your Java/C++ knowledge will transfer easily later.

---

## Week 1 — Foundations: Git, GitHub & Problem-Solving Mindset
**Milestone:** Have a GitHub profile with your first repo, and be comfortable writing simple Python functions to solve problems.

| Day | Task | Resource |
|---|---|---|
| 1 | Install Git, learn `init`, `add`, `commit`, `push`, `pull` | freeCodeCamp "Git and GitHub for Beginners" (YouTube) |
| 2 | Create a GitHub account, make your first repo, push a "Hello World" Python file | GitHub Docs — Quickstart |
| 3 | Learn branching (`branch`, `checkout`, `merge`) with a practice repo | freeCodeCamp Git video (continue) |
| 4 | Python refresher: lists, dictionaries, loops, functions — solve 5 easy problems | HackerRank "Python (Basic)" track |
| 5 | Solve 5 more easy problems; write clean functions with comments | LeetCode Easy (Array/String tag) |
| Buffer | Review the week, fix any Git mistakes, clean up your repo's README | — |

**Weekly Project:** A GitHub repo called `python-warmups` containing your 10 solved problems, each in its own file with comments explaining your approach.

---

## Week 2 — Data Structures & Algorithms Basics
**Milestone:** Understand and implement core data structures; solve basic algorithm problems confidently.

| Day | Task | Resource |
|---|---|---|
| 6 | Arrays & Strings: time complexity basics (Big-O intuition) | "Big O Notation" — freeCodeCamp or CS Dojo (YouTube) |
| 7 | Implement a Stack and Queue from scratch in Python | mycodeschool (YouTube) — Stacks & Queues |
| 8 | Linked Lists: implement singly linked list (insert, delete, traverse) | mycodeschool — Linked List series |
| 9 | Recursion basics: factorial, Fibonacci, sum of list | CS50 "Recursion" lecture (YouTube) |
| 10 | Solve 5 LeetCode Easy problems using arrays/strings/recursion | LeetCode Easy |
| Buffer | Re-attempt any problem you struggled with, without looking at the solution | — |

**Weekly Project:** A `data-structures` repo with your own working implementations of Stack, Queue, and Linked List — each with a small test/demo script showing it works.

---

## Week 3 — Web Development Basics (Build Something Real)
**Milestone:** Build and deploy a simple interactive web app using your existing HTML/JS skills + basic Python backend concepts.

| Day | Task | Resource |
|---|---|---|
| 11 | Refresh HTML/CSS layout basics (Flexbox) | Kevin Powell "Flexbox in 15 Minutes" (YouTube) |
| 12 | JavaScript DOM manipulation refresher: events, `querySelector` | freeCodeCamp "JavaScript DOM" video |
| 13 | Build a to-do list app (HTML+CSS+JS only, no backend yet) | Follow-along project (freeCodeCamp) |
| 14 | Intro to Flask (Python web framework) — build a "Hello World" server | Corey Schafer "Flask Tutorial #1" (YouTube) |
| 15 | Connect a simple form (HTML) to your Flask backend to store/display data | Corey Schafer Flask series (continue) |
| Buffer | Polish your to-do app's UI; add basic styling | — |

**Weekly Project:** A **To-Do List Web App** — frontend in HTML/CSS/JS, with a Python Flask backend that saves tasks. Push to GitHub with a clear README.

---

## Week 4 — Portfolio Project + Interview & Career Prep
**Milestone:** Ship a polished project you can show recruiters, and know the basics of technical interviews.

| Day | Task | Resource |
|---|---|---|
| 16 | Plan a final capstone project (see suggestions below); sketch features | — |
| 17 | Build core functionality of your capstone project | Your choice of tutorial matching the project |
| 18 | Continue building; add error handling and edge cases | — |
| 19 | Deploy your project (e.g., GitHub Pages for frontend, Render/PythonAnywhere for Flask) | "Deploy Flask App for Free" (YouTube search) |
| 20 | Write a great README (what it does, tech used, how to run it, screenshots) | "How to write a good README" — freeCodeCamp article |
| Buffer | Record a 2-min screen demo of your project (great for LinkedIn/portfolio) | — |

**Capstone Project Ideas (pick one, matched to your skills):**
- **Personal Portfolio Website** — showcase your projects (HTML/CSS/JS)
- **Expense Tracker** — Flask + simple database (SQLite) to add/view/delete expenses
- **Quiz App** — JS-based quiz with score tracking, styled nicely
- **Weather Dashboard** — fetch data from a free weather API, display with JS

---

## Final Outcome (After 30 Days)
By the end, you will have:
1. ✅ A GitHub profile with **3 repos**: warmups, data structures, and a capstone project
2. ✅ Solid understanding of **Git/GitHub workflow**
3. ✅ Working knowledge of **core data structures** (Array, Stack, Queue, Linked List) and **Big-O basics**
4. ✅ Experience solving **~15 coding problems** independently
5. ✅ A **deployed, working web application** you can show in interviews or add to your resume
6. ✅ A foundation to continue into deeper DSA (LeetCode Medium), or a specific stack (e.g., React, Django) next

---

## Tips for Success
- **Consistency > intensity.** 45 min daily beats a 5-hour weekend cram.
- **Type code yourself** — don't copy-paste from tutorials. Pause videos and try first.
- If a day's task takes longer than planned, it's fine to spill into the buffer day.
- Keep a simple **learning log** (even a text file) noting what you learned and got stuck on each day — this is gold for interview "tell me about a challenge" questions later.
